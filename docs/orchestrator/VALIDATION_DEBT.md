# Validation debt

## Purpose
This ledger records real, repo-level issues that are out of scope for the current Heureka onboarding pass and should be tracked separately from current-task failures.

## Rules
- Only document issues that are real and traceable to the repo’s operational boundary.
- Keep entries factual, bounded, and actionable.
- Do not use placeholder markers such as `REPLACE_ME`, `TBD`, or `TASK-XXX`.

## Entries
- No current validation debt is recorded for the Heureka onboarding profile.

## Update format
- Date: 2026-08-31
- Issue: brief summary
- Owner: repository owner or responsible maintainer
- Status: open or resolved
- Next action: concrete closure step
